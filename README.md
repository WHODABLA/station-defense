# Station Defense (multiplayer)

Co-op space station defense. Up to 8 pilots per room, bots fill empty seats.

Files: `game-server.js` (server), `game.html` (client), `package.json`.

## Run locally
    npm install
    npm start
Open http://localhost:3000

## Deploy on Render (free)
1. Push these files to a GitHub repository (files at the repo root).
2. Render > New > Web Service > connect the repo.
3. Build command: `npm install`  |  Start command: `npm start`
4. Open the URL Render gives you. Friends who open the same URL can join.

Play with friends: everyone types the same room code on the menu.
Leave it blank to join a public match.
