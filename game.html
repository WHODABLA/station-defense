Station Defense

Co-op for up to 8 pilots, with bots filling empty seats. Type the same room code as your friends to play together, or leave it blank to join a public match. Scrap is rare, so hunt for it, then build turrets, repair the station and upgrade your weapon. If every pilot or the station falls, the run ends.

Mobile: left thumb moves, right thumb aims and fires. Desktop: WASD, mouse, keys 1/2/3.
